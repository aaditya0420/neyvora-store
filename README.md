# NeyVora

Rebuilt source for the NeyVora luxury beauty storefront, matching [neyvorastore.netlify.app](https://neyvorastore.netlify.app/).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

```bash
npm run build
```

Then drop the `out` folder (if you add `output: "export"` to `next.config.ts`) or deploy the Next.js app to Netlify / Vercel.

Checkout, contact, newsletter and account are frontend demonstrations — no payment or server is involved.
